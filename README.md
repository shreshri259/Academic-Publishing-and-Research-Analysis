# Academic Publishing & Research Analysis

**Portfolio project by Shreyas Shriwastav**

An end-to-end exercise in **scientific literature analysis, structured data extraction, quantitative analysis, and editorial quality assurance**, designed to demonstrate transferable skills relevant to entry-level scholarly publishing, editorial operations, content quality, and research-content roles.

---

## Project Overview

This project uses one peer-reviewed scientific article as a realistic publishing-content case study. The workflow moves from understanding the research question through to structured data extraction, quantitative analysis, and manuscript-level editorial QA.

The project was intentionally designed to keep **source-derived information, derived analysis, and editorial judgement separate and traceable**.

### Workflow

```text
Scientific Article
       ↓
Research Summary
       ↓
Structured Metadata & Experimental Variables
       ↓
Quantitative Data Extraction
       ↓
Data Validation & Analysis
       ↓
Editorial QA in Microsoft Word
       ↓
Issue Tracking / QA Log
       ↓
Final Portfolio Report
```

## Source Article

**Najm, A. S., Naeem, H. S., Majdi, H. S., et al. (2022).**  
*An in-depth analysis of nucleation and growth mechanism of CdS thin film synthesized by chemical bath deposition (CBD) technique.*  
**Scientific Reports, 12, 15295.**

- **DOI:** `10.1038/s41598-022-19340-z`
- **Original article:** https://www.nature.com/articles/s41598-022-19340-z
- **PubMed record:** https://pubmed.ncbi.nlm.nih.gov/36096904/
- **Open-access full text:** https://pmc.ncbi.nlm.nih.gov/articles/PMC9468032/

The article studies CdS thin films prepared using chemical bath deposition and examines their optical, structural, morphological, and electrical properties.

> **Source-use note:** This repository should contain the analysis and portfolio materials, not a redistributed copy of the publisher's article. Use the links above to access the original paper.

## Project Objectives

1. Understand and summarise the research problem, objective, materials, methodology, variables, findings, and scope of a scientific paper.
2. Convert selected source information and published measurements into structured, analysis-ready data.
3. Perform transparent quantitative comparisons and visualisations without treating derived observations as new experimental results.
4. Practise editorial quality assurance using Microsoft Word Track Changes and Comments.
5. Record editorial issues systematically with severity, recommended action, action taken, and status.
6. Produce a concise professional report suitable for a publishing/data-content portfolio.

## Repository Contents (Core deliverables)

| File | Purpose |
|---|---|
| `Scientific article` | PDF copy of the research paper in question for reference |
| `Research_Summary.docx` | Structured scientific reading: research problem, objective, materials, experimental method, characterization techniques, variables, findings, conclusion, and open questions |
| `Data_Analysis_and_Metadata_Extraction.xlsx` | Article metadata, experimental variables, source-derived Tables 1, 4, and 5, cleaned electrical data, analysis, charts, and QA checks |
| `Editorial_QA_Sample.docx` | Continuous Introduction excerpt reviewed in Microsoft Word using Track Changes and author-facing Comments |
| `Editorial_QA_Sample_log.xlsx` | Issue-level editorial QA log containing category, location, recommended action, action taken, severity, and status |
| `Final_Report.docx` | Consolidated portfolio report describing the project, methodology, analyses, QA process, findings, scope, and demonstrated skills |

## Tools Used

- **Microsoft Word:** document editing, Track Changes, Comments, formatting and editorial review.
